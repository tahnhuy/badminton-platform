# Frontend UI examples

Hai ảnh đại diện để tham khảo giao diện hiện đã triển khai, không phải bộ kết quả kiểm thử đầy đủ hay ảnh của sản phẩm đã hoàn tất.

- [Chi tiết sân — desktop](court-detail-desktop.png): D04, bố cục và hệ thống màu chung.
- [Lịch sử đặt sân — mobile](booking-history-mobile.png): D06, thẻ đơn và điều hướng mobile.

Chỉ thay thế các ảnh này khi cần cập nhật minh họa có giá trị lâu dài; không thêm ảnh theo mỗi đợt hoặc mỗi lần chạy. Kết quả kiểm tra được tóm tắt trong báo cáo đợt; JSON/log/trace/ảnh debug nằm ngoài Git.
